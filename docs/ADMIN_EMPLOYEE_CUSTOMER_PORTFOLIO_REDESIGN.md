# Admin Employee Customer Portfolio redesign

Implemented 7 November 2026 for `/admin/customers/employees/:employeeId`.

## Changes

- Removed the padded, bordered outer card and maximum-width constraint. The page now uses the existing Admin content area, with compact breadcrumbs, employee metadata, request/add actions and horizontal separators.
- Reused the existing server-side search, customer status, KYC status, loan filters, sort controls, page size and pagination. Advanced controls collapse below 768px and remain a two-row toolbar on wider screens.
- Added a reusable presentation component for full-width desktop/tablet tables and mobile customer cards. Secure customer photos, initials fallback, photo preview, customer routes and keyboard row navigation are reused.
- Reused the batch risk API and existing details dialog. The badge shows the actual policy category and score, with publication status in its tooltip and the full existing explanation in the dialog.
- Corrected the *display order* of loan counts to Active / Total, matching its label. No calculations changed.
- Preserved KYC revision indicators, customer status, occupation, location, mobile, overdue installment counts and last received date. Dates continue to use Asia/Kolkata.
- The shared page also serves All Customers, Unassigned Customers and embedded assigned portfolios; unscoped lists retain employee assignment information.
- No backend code, API contract, database record, authorization, financial calculation or navigation shell was changed.

## Approved reference refinement — 7 November 2026

The supplied `Royal Enterprises Customer Portfolio UI (1).png` was used to refine the earlier design.

- Employee name/code breadcrumb, left-aligned Back link and compact gold portfolio icon/header.
- Main filters now share one desktop row (two rows at tablet/narrow laptop widths); mobile has full-width search followed by four compact selects. Sort direction and server page-size controls are retained in the footer.
- Table identity groups the existing secure photo/initials, name, occupation, customer code/mobile and compact risk badge. Typical synthetic laptop rows measured about 99px.
- Compact mobile cards display Outstanding, Overdue and Active / Total loans in one row, with visible KYC/account badges and View Details. Location, last receipt date, revision indicators and overdue counts remain accessible in expandable metadata.
- Existing shared photo preview and risk modal, exact customer routes, keyboard row actions and request/add links remain in use. No new actions or scoring rules were invented.
- Only the existing portfolio page, its presentation component, its scoped CSS and its regression tests were edited for this refinement. Settings, Collections, shared shell, logo assets and backend code were not edited. Existing unrelated uncommitted work was preserved.
